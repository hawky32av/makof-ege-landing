# Новый лендинг Дмитрия Макова

Новый сайт создан с нуля и не зависит от предыдущего makof.ru или его исходников.

## Идея

Короткий рекламный лендинг с мягким первым действием: **«Обсудить подготовку»**.

Структура:
1. Оффер.
2. Обо мне и доказательства квалификации.
3. Результаты учеников.
4. Как устроена подготовка.
5. Первый разговор + форма.
6. Подвал.

## Что нужно подключить перед публикацией

- реальную фотографию Дмитрия;
- скан диплома ИТМО;
- удостоверение о подготовке экспертов ЕГЭ;
- обложку и пример страницы учебника;
- подтверждения результатов, если хотим открывать их из карточек;
- фрагмент лекции Rutube;
- форму AlfaCRM вместо демо-формы;
- реальные ссылки на оферту, политику обработки данных и согласие;
- Яндекс Метрику и цели после финальной настройки формы.

## Локальный запуск

Сайт статический. Достаточно открыть `index.html` либо запустить любой статический сервер:

```bash
python -m http.server 8080
```

После этого открыть `http://localhost:8080`.
